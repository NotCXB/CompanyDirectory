Recursive insertion works by searching through the binary tree to find the manager that an employee will be added under. The script would start at my root node, which was the team lead, and would then compare the current employee name to the manager's name entered by the user. If the names successfully matched, my script would then check if either the left or right position is available. If unsuccessful, the function would keep searching recursively through the existing child nodes until it found the correct manager or searched through the who tree. 
One challenge I faced when finding the right spot was making sure employees were inserted into the right spot while not overwriting previous entrees. Each node will then have two children, and then the program will verify if the position that's requested is free before inserting it. Another challenge was handling situations where the manager didn't exist. By utilizing error messages, it helped prevent incorrect modifications. 
Trees are preferable to other data structures in real-world systems when information is in a hierarchical structure. Companies may use trees to represent management relationships, and computers use them to structure file directories and organizational structures. Trees make it easy to navigate relationships between different hierarchies of information. Overall this assignment helped me understand how recursion and trees can organize information in real world uses.
